# SkyArena Game Client

Unity 6 LTS game client.

## Current milestone

Phase 1 vertical slice.

## Responsibilities

- Player movement
- Camera
- Combat
- Weapons
- Jetpack
- Health/damage
- Respawn
- Bots
- Match flow
- HUD
- Animation/VFX/audio integration

## Unity project

Open this directory as the Unity project root.

Do not place server secrets or production credentials in this project.
